# DocMatch v1.8.31

Versi ini menggabungkan ketelitian pembacaan dari source `DocMatch_v1.8.30.9_r2.zip` dengan antarmuka ringkas dan responsif `DocMatch_v1.8.30.10_Compact_Flexible_Layout.zip`.

## Instalasi
1. Ekstrak ZIP ke folder baru; jangan menimpa versi sebelumnya sebelum diuji.
2. Pastikan dependensi Python sesuai instalasi DocMatch (termasuk PyMuPDF dan PySide6).
3. Jalankan `py preflight.py` lalu `py docmatch.py`.
4. Pilih mode SWB yang sesuai; jalankan pembandingan dan periksa hasil Tahap 1/Tahap 2.

## Catatan pengujian
Tes otomatis lulus untuk kode yang dapat diuji di lingkungan pengembangan. Uji dokumen GSL asli dan GUI Windows masih diperlukan untuk validasi final.

Lihat `CHANGELOG_v1.8.31.md` untuk rincian perubahan.
