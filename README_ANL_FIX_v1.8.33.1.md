# Panduan pengujian ANL/CNC/CMA CGM

1. Pilih surat rujukan yang memiliki label parameter pada Dokumen A.
2. Pilih dokumen carrier ANL/CNC/CMA CGM asli pada Dokumen B.
3. Pilih mode `SWB - ANL/CNC/CMA CGM` dan parameter yang relevan.
4. Klik Bandingkan. Periksa Vessel, Voyage Number, Waybill Number, Shipper, Consignee, Notify Party, Port of Loading dan Port of Discharge.
5. Periksa field `Perlu Verifikasi` secara terpisah dari daftar Mismatch. Jangan berharap surat uji sintetis cocok dengan dokumen carrier dari pengiriman berbeda.
6. Bandingkan hasil dengan v1.8.33 jika ingin melihat perubahan akibat perbaikan klasifikasi.

Tidak ada perubahan pada layout visual aplikasi. Jika hasil B masih salah, sertakan pasangan PDF ANL asli (bukan screenshot saja) agar koordinat profil dan alias dapat diuji langsung.
