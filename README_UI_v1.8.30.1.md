# Panduan UI Hasil & Ekspor v1.8.30.1

1. Jalankan `py preflight.py`, lalu `py docmatch.py`.
2. Pilih dokumen, atur parameter, lalu bandingkan.
3. Buka **Hasil & Ekspor**. Toolbar (ribbon) khusus hasil akan muncul di bawah navigasi langkah.
4. Grup **Validasi**: Validasi Tahap 2, Edit Koreksi, Catatan Koreksi.
5. Grup **Ekspor Laporan**: Ekspor DOCX, Ekspor PDF, Ekspor JSON.
6. Panel **PDF Rujukan** dan **PDF Diperiksa** menampilkan halaman seimbang, dapat di-resize dengan separator di tengah.
7. Klik **Lebar** pada masing-masing panel agar PDF mengisi lebar tersedia. Mengklik +/- mematikan auto-fit pada panel terkait.
8. Di kanan, pilih tab **Tahap 1 · Ketidaksesuaian** atau **Tahap 2 · Penanda**. Checkbox Tahap 2 tetap mengontrol overlay yang diekspor.

Tidak ada perubahan terhadap file PDF sumber. Backup versi sebelumnya sebelum mengganti file.
