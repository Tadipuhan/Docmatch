DocMatch v1.8.11 — Perbaikan pergantian dokumen dan status pemeriksaan

Basis: DocMatch_v1.8.10_GSL_Field_Fix.zip

Perubahan:
- Pemilihan PDF/DOC/DOCX langsung memuat preview di panel rujukan/diperiksa.
- Pergantian dokumen membatalkan hasil perbandingan sebelumnya, stabilo, daftar temuan, editor dan catatan lama.
- Ekspor dinonaktifkan sampai perbandingan baru sukses.
- Pergantian preset juga membatalkan hasil lama tanpa menghilangkan preview dokumen.
- Error preset GSL untuk dokumen dua halaman kini menjelaskan kemungkinan preset salah (misalnya Evergreen).
- Versi pada judul jendela menjadi 1.8.11.

Catatan: Ini patch alur GUI. Akurasi OCR GSL dan pencocokan field belum diklaim selesai.
Pengujian GUI di Windows dan build portable tetap diperlukan.
